Welcome to the TODO Projects repository! This project consists of multiple phases, each building upon the previous to create a comprehensive full-stack application with AI-powered features.

### Phase 2: Full-Stack Web Application
- **Live Demo**: [https://hackathon-2-phase-2-nine-theta.vercel.app/](https://hackathon-2-phase-2-nine-theta.vercel.app/)
- A complete full-stack web application with user authentication, CRUD operations, and responsive design.

### Phase 3: AI-Powered Todo Chatbot
- **Live Demo**: [https://hackathon-2-phase-3-front.vercel.app/](https://hackathon-2-phase-3-front.vercel.app/)

## 📋 Project Overview

This multi-phase project demonstrates the evolution of a simple in-memory console application to a sophisticated full-stack web application with AI capabilities.

### Phase 1: In-Memory Python Console App
- Built with Python
- Basic TODO functionality in console
- Foundation for data structures and business logic

### Phase 2: Full-Stack Web Application
- Modern web interface with React/Next.js
- Backend API with authentication
- Database integration for persistent storage
- Responsive design for all devices

### Phase 3: AI-Powered Todo Chatbot
- Natural Language Processing for todo management
- Conversational AI interface
- Smart task categorization and suggestions
- Advanced filtering and search capabilities

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- Python (v3.8 or higher)
- npm or yarn
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/TODO-Projects.git
cd TODO-Projects
```

2. Navigate to the specific phase you want to run:
```bash
cd Phase-2-Full-Stack-Web-Application  # or Phase-3-AI-Powered-Todo-Chatbot
```

3. Install dependencies:
```bash
# For frontend applications
npm install

# For Python applications
pip install -r requirements.txt
```

4. Set up environment variables:
```bash
cp .env.example .env
# Update the .env file with your configuration
```

5. Run the application:
```bash
# For frontend applications
npm run dev

# For Python applications
python app.py
```
